# Документы

Папка для файлов, которые сайт предлагает скачать.

## Книга об ордене Odd Fellows

Загрузите сюда PDF-файл книги и назовите его ровно так:

```
Odd_Fellows_Book_RU.pdf
```

Сайт уже ссылается на `docs/Odd_Fellows_Book_RU.pdf` в разделе «Документы» — как только файл с этим именем появится в этой папке, кнопка «Скачать PDF» на сайте заработает.
